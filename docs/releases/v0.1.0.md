첫 공개 버전입니다. 복사·스크린샷·다운로드를 자동으로 모으고, `⌘⇧Space` 한 번으로 다시 찾습니다.

**설치:** 아래 `Digital-Desk-0.1.0-universal.dmg`를 받아 Applications로 옮기세요. 서명·공증되지 않은 앱이라 처음 열 때 경고가 나옵니다 — [README의 설치 방법](https://github.com/yoon-yoo-tak/digital-desk#설치)대로 **시스템 설정 › 개인정보 보호 및 보안 › 그래도 열기**를 한 번 눌러 주세요.

### 들어 있는 것
- 클립보드(텍스트·링크·이미지·파일), 스크린샷, 다운로드 자동 기록 — 비밀번호 관리자와 제외 앱은 기록하지 않음
- 스크린샷 OCR(한국어·영어, 기기 안에서)
- Quick Search: 날짜 표현(`지난주`, `어제`, `last week`…), `type:` `app:` `domain:` 필터, 한↔영 동의어(`에러` → `Exception`), 같은 작업 묶음
- 메인 창: Inbox · Desk(고정) · Archive, 삭제 되돌리기(⌘Z)
- 메뉴바 일시정지, 최근 5분/1시간 삭제, 보관 기간, 설정, 첫 실행 온보딩
- 데모 프로필: `open "/Applications/Digital Desk.app" --args --profile=demo` — 샘플 데이터로 바로 시험해 볼 수 있습니다

### 알려진 제한
- 서명·공증 전이라 첫 실행에 "그래도 열기"가 필요합니다
- "로그인 시 실행"은 서명되지 않은 앱에서 macOS가 거부할 수 있습니다
- 새로 설치한 뒤 첫 스크린샷의 글자 인식은 macOS가 모델을 준비하는 동안 수십 초 늦을 수 있습니다(앱은 시작할 때 미리 준비합니다)
